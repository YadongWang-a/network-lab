## 决议（2026-09-07 交付）

解析器从「写 DOM 属性」迁移为**纯文本 → 类型化配置对象**模块 `src/parsers/config.ts`（不依赖 DOM/React，可单测），错误带行号中文（`配置错误（第 N 行）：…`）：

- `parseNetworkInterfaces`：`iface <iface> inet static|dhcp [address/netmask/gateway]`（语法沿 legacy parser-network-file；路由规则由 WF-7 自动路由覆盖，不解析——标注范围）。
- `parseDhcpdConf`：`subnet … { range / option routers / option subnet-mask / option domain-name-servers / default-lease-time }`，兼容单行块（花括号/分号归一化）；host 保留地址块后置不解析。
- `parseNamedConfLocal` + `parseDbFile`：zone → db 文件映射；`<host> [IN] A <ip>`（`@` = zone 顶点 → FQDN）。
- `parseApacheVhost`：`<VirtualHost>` 块内 ServerName / DocumentRoot。
- 校验工具 `isValidIpv4`/`isValidCidr4`/`parseCidr4` 供后续复用。

**落 store 接线**（终端 `systemctl start|restart` 触发，WF-11）：dhcpd → `device.dhcpPool`（含新增可选 `netmask` 字段，offer/ack 下发掩码可覆盖接口掩码）；named → `services.named.config.zones`；apache2 → `services.apache2.config`。非法配置（行号）打印到终端，不污染状态。
