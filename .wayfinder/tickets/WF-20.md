## Question

参照 `数据包可视化演示_单视图整合版.html` 的「包解剖」形态，在报文追踪面板内做真实报文的包解剖视图：

- 点击一条追踪行，在追踪面板下方**内联**展示该包的解剖——**不要对话框**（现有「报文详情悬浮窗」移除）。
- 解剖内容三件套：层条（横向彩条，flex 按层头字节数，点层切换）+ 字段/值/说明表 + hex 视图（点层高亮对应字节段）。
- 引擎报文无序列化字节：hex 由层字段**合成真实包头字节**（以太网/IP/TCP/UDP/ICMP/ARP 可精确合成）；应用层负载（HTTP/DHCP/DNS）为示意字节并明确标注。
- 复用已有 `layerFields` 口径与 i18n；文案走 zh/en locale。

## Resolution

**落地（2026-09-08，reference = 数据包可视化演示_单视图整合版.html）**：

- `src/domain/packetBytes.ts` — 纯函数字节合成器：以太网/ARP/IP/ICMP/TCP/UDP 按 RFC 形状精确编码（校验和 0x0000 占位），应用层（DHCP BOOTP 240B+option53 / DNS 编码 / HTTP 文本）按字段忠实编码并标 `approx`；输出字节序列 + 各层字节区间。
- `src/ui/PacketDissect.tsx` — 解剖组件三件套：层条（flex 按字节数，点层切换，approx 层带 *）+ 字段/值/说明表（说明走 `desc.*` i18n）+ hex 视图（16B/行，选中层高亮字节段）。
- `src/ui/App.tsx` — 追踪面板 List 下方内联解剖区（46% 高度，独立滚动）；点行 = 选中 + 画布重放；**移除报文详情悬浮窗**（`details`/`openDetail`/`startDragPanel`/`layerFields` 整删，选中行加底色）。
- i18n：zh/en 各 +42 key（`dissect.*` + `desc.*`），删孤儿 `packet.*` 6 key。
- 测试：`tests/domain/packet-bytes.test.ts` 9 用例（字节形状/段连续/approx 标注）；e2e ping 用例追加「点行 → 层条 + hex + 字段表」断言。

**验收**：tsc ✓、vitest 34/34、e2e 4/4 连续两轮、vite build ✓、eslint 0 error；浏览器实测（会话内截图验证）：ICMP/以太网层切换、hex 高亮区间随层联动、无对话框。
**踩坑**：antd v6 `aria-controls` 指向 0 高的虚拟列表包裹层（Playwright 判 hidden），e2e 定位须锚到可见的 `.ant-select-dropdown` 祖先（`:has([id=…])`）。
