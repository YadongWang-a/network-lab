## 决议（2026-09-07 交付）

`unix.js` 终端重写为 **React 终端组件 + 命令注册表**（替代 legacy `commandFunctions` 硬编码与 mock 迷你 shell）：

- **注册表** `src/terminal/commands.ts`：`Record<string, CmdHandler>`，命令经 `TermCtx`（设备 id / 行输出 / 每窗独立 SimulationEngine / cwd / busy / close）访问 store 与引擎，天然可扩展（新命令注册即用）。
- **命令集合（全部真跑）**：
  - 文件系统：`pwd/cd/ls/cat/echo(> >>)/mkdir/touch/rm[-r]/mv/cp` —— 底层 `src/domain/filesystem.ts` 纯函数操作设备虚拟 FS（Device.filesystem，写回 store），错误中文。
  - 网络：`ip a`（接口/mac/掩码/网关 store 真身）、`arp`（本机 ARP 表）、`arpscan`（真引擎逐主机探测+汇总）。
  - 引擎驱动（流式实时输出，`driveEngine` 逐事件回调）：`ping <ip>`（4 条应答逐条 + 统计）、`traceroute <ip>`（逐跳）、`dig <域名>`（named 应答）、`systemctl start isc-dhcp-client`（同网段 DORA 绑定）。
  - 配置接线（WF-10）：`systemctl status|start|stop|restart <unit>`（isc-dhcp-server / isc-dhcp-client / bind9 / apache2 / iptables）——restart 读取设备 FS 中真实守护进程配置（/etc/dhcp/dhcpd.conf、named.conf.local+db、apache vhost）经解析器落 store。
- **终端 UI** `src/terminal/TerminalBody.tsx`：↑/↓ 命令历史、当前设备上下文（root@label:/cwd# 提示符随改名/切目录更新）、busy 态输入禁用、实时输出流、卸载清理引擎等待者；Shell 悬浮 Card 承载，设备删除后窗口安全降级。
- **标注范围**：nano/man/apt/curl/visual/realnode 等未迁移命令不在注册表（help 列出可用集）；rm 删除目录需 `-r`；cp 暂不支持目录。
- 顺带修复：`driveEngine` 原按「首跳去重」回调导致定向末跳（如 echo-reply）永远到不了终端收集器 → 改逐事件回调、由各命令按 `to=本机` 过滤；`mkdir /tmp/m4` 需先建父目录（同 POSIX，无 `-p`）。
