## Question

用户要求：路由器属性面板的「网络接口」区应「连接哪些端口就显示哪些，没连接的不显示」。

现状（WF-22 裁剪、WF-25 追加端口后暴露）：抽屉无差别列出 `Object.values(selected.interfaces)` —— 路由器未接线的端口（含 WF-25 的空闲备用口，无 IP、不参与 WF-7 路由）也占据表单。

## 落点

1. `src/ui/App.tsx` 抽屉「网络接口」区改为 IIFE：`Object.values(interfaces).map((f, i) => ({f, i})).filter(({f}) => selected.kind !== 'router' || f.connectedSwitchId !== null)`；空列表渲染灰色空态提示。**字段名仍用接口表中的原序号**（`ip${i}`/`mask${i}`/`gw${i}`），`onFinish` 的按序号回填逻辑零改动（被隐藏项无值 → `undefined` → 跳过写入）。
2. i18n：新增 `drawer.noWiredIface`（zh/en）。

## Resolution（2026-09-12）

路由器抽屉只列**已接线**端口；非路由器设备（PC/DNS/DHCP/中继，均单接口）不受影响。未接线端口不再可预配 IP —— 与 WF-7「线缆感知」语义一致（未接线接口本就不参与路由），需要配置时先接线，行即出现。空列表（新拖入的路由器）显示：`（未连接端口：在画布上拉线后，此处显示对应接口）`。

验收证据：

- `tsc --noEmit` ✓；`vitest` 40/40 ✓；`eslint .` ✓；locale 键对齐 zh/en 219 = 219（无孤儿）✓；Playwright 4/4 ✓。
- 浏览器实测（headless 真实拖拽）：路由器 0 根线 → 空态提示、0 行；接 3 根线（画布上已有 4 个端口，第 4 个 `enp0s10` 为未接线备用口）→ 抽屉恰列 `enp0s3/enp0s8/enp0s9` 三行及其 IP，**未接线的 enp0s10 不出现**；PC 抽屉仍列 `enp0s3`。
- 编辑回归：在抽屉把 `enp0s8` 的 IP 改为 `10.0.0.77` 保存 → 画布端口标签同步显示 `10.0.0.77`（序号式字段名映射未被过滤破坏）。
- 视觉复核（截图 `.wayfinder/ui-wf26.png`）：网络接口区三块，标签/输入无空块或重复，IP 与画布端口标签、路由表直连条目一致。
