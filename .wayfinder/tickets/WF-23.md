## Question

用户指出：PC 属性面板没有 DHCP 开/关配置，「怎么模拟 DHCP 开放」不直观。现状（WF-17 语义）：

- 引擎 `dhcpDora` 已真驱动 DORA，但**仅当接口无 IP 才绑定**（`SimulationEngine.ts:741-744`）；
- `deviceFactory` 创建即按 WF-6 IPAM 分静态 IP（.2 起），故种子 PC 永远静态；
- 触发只能靠演示命令「DHCP」或终端 `dhclient`——手动、且要求先手动清空 IP，不直观。

需要决策：

1. **开关形态**：PC（含其他终端设备？）抽屉加「DHCP 客户端」开关，落 `services.dhclient.enabled`（ServiceName 已有）？
2. **IPAM 语义**：DHCP 开启的设备创建时是否不再分静态 IP（ip=null）？WF-6 语义变更面。
3. **触发时机**：开关打开/连线到有 dhcpd 的广播域时自动 DORA，还是保持手动触发（开关只改绑定规则与展示）？涉 MAP fog「自动配置交互形态」与播放/复位语义。
4. **绑定规则**：DHCP 开启时是否允许覆盖已有静态 IP（改写 vs 先清空 vs 拒绝）？
5. **UI 联动**：开关开时 IP/网关字段是否转只读（显示租约值），手填 IP 是否等价于关 DHCP？
6. **适用面**：仅 PC，还是 DNS/DHCP 服务器/中继等所有终端类设备（服务器类真实世界通常静态，倾向排除）？

## Resolution（2026-09-09，用户逐题拍板）

- **触发时机 = 保持手动**：获取地址仍走演示命令「DHCP」或终端 `dhclient`；引擎「无 IP 才绑定」语义零改动。
- **默认态 = 关 + 开关切换**：新设备仍默认静态 IP（IPAM/WF-6 不变），种子/e2e 零改动。
- **UI 联动 = 互斥**：开关开 → 接口静态 IP/掩码/网关清空、字段转只读（DORA 后显示租约值，未获取时提示 `drawer.dhcpHint`）；关 → 重新走 IPAM 分配静态地址（扫当前拓扑占用）。
- **适用面 = 仅 PC 类**（`kind=pc`，含 apache2 归并体）；服务类设备不出开关。

落地：store 新增 `setDhcpClient`（开=清静态+标记 `services.dhclient`，关=`SubnetPool.allocateEndDevice` 重分配，池耗尽抛中文错误；经 `applyRouting` 收口）；PC 抽屉加「DHCP 客户端」开关 + 字段 `disabled` 联动 + 租约提示；Form key 含 DHCP 态（切换即重挂载，避免表单显示滞后）；onFinish 在 DHCP 态跳过接口写入（防只读值回写）。i18n +2 key（zh/en 对齐 212）。**引擎零改动**。

验收：tsc ✓；vitest 34/34；e2e 4/4；浏览器全流程实测——开（IP 清空+字段禁用+提示+名牌 IP 消失）→ 演示命令 DHCP 四步（PC-0 经 DHCP-0 获 192.168.1.100，掩码/网关同步绑定，字段只读）→ 关（IPAM 重分配回 192.168.1.2，字段即时可编辑）。
