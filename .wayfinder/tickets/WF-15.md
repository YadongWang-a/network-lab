## Question

把运行中的原型拓扑数据流（D1）从本地 `useState` 换成 `store.topology`：画布设备/连线/编辑成为 store 的投影与写入口，WF-6/7 自动配置与路由重算随之真正生效。仿真（D2）保持假数据不动，保证 M1 验收只聚焦拓扑一致性。

## Notes（接线面清单，行号已核于 2026-09-03 摸底）

替换四处：

1. **种子拓扑**：`seedNodes`（L288-294）/`seedEdges`（L296-301）→ 挂载时用 `store.addDevice`/`addConnection` 灌入（switch 先建，设备后连；与 store 校验兼容）。
2. **拖放建设备**：`onDropDevice`（L384-432）删内联 `SubnetPool` 副本 → `store.addDevice(kind, {position})`（id/标签/分配全由 store 定，顺序注意 addDevice 的 `deviceSeq` 与原型 `seq` 冲突处理）。
3. **拉线**：`onConnect`（L968）→ `store.addConnection(deviceId, ifaceId, switchId)`。**连线语义 = 交换机终端**（WF-14 决策）：目标非 switch 时拒绝并提示（文案走 i18n）。原型节点只有一个中心 source Handle（L216-242）——接线面设计点：路由器多接口时选「第一个空闲接口」（`connectedSwitchId==null`），全忙报中文错；也可先做单接口设备（PC/服务）+ 路由器三接口顺序选。
4. **编辑**：配置 Drawer `onFinish`（L1141-1146）→ `updateDevice`/`updateInterface`；IP/掩码变更后路由表自动重算（store 已内置触发）。

配套改动：

- `DeviceNodeView`（L208-265）从扁平 `DeviceData` 改接 store 真 Device：节点 data 只存 deviceId + kind（图标/名牌用），其余字段经 selector 订阅；未配置 IP 以 `ip==null` 为单事实源，'—' 仅展示层（i18n key 已存在 `device.unconfigured`）。
- 节点/边数组 = `topology` 的派生投影（`useStore` selector + 记忆化），拖拽位置变化写 `updateDevice(id,{position})`（store 对非路由键 patch 不触发重算，见 updateDevice 实现）。
- Drawer services/firewall 静态区（L1157-1181）可顺带切到真 Device 字段展示（浅读即可，深改留 WF-11/17）。
- 连线校验、报错、位置同步等新增文案进 zh/en locales（勿模块级固化，沿用 useTranslation 或 i18n.t 双模式现状）。
- **验收门**：拖放 PC/路由器/交换机→地址分配与路由表重算与 store 一致；连非交换机被拒且提示中文；断开（需要时补 removeConnection UI 入口或画布双击删边）；配置抽屉保存后画布名牌/路由表同步；9 个演示命令仍可运行（假仿真未动）；`tsc --noEmit` + `pnpm build` 绿。
